The big picture

Remember this

  • ax2 + bx + c = 0 draws a parabola. Its roots are where it hits the x-axis.
  • Count the roots with b2 − 4ac: positive → 2 · zero → 1 · negative → 0.
  • Picture it: is the vertex below, on, or above the axis?
  • Find the roots by factoring if the numbers are nice; otherwise use x = −b ± √b2 − 4ac2a.

What a quadratic is

A second-degree polynomial ax2 + bx + c = 0, where a, b, c are constants and a ≠ 0.

Rules

  • Opens up ∪ when a > 0, down ∩ when a < 0. a is the number in front of x2, wherever that term is written.
  • The turning point is the vertex, at x = −b2a. Plug that x back in to get the vertex's y.
  • Opens up → the vertex y is the minimum value. Opens down → it's the maximum.
  • Solving … = 0 asks “where is y = 0?”, which is where the curve meets the x-axis.
Show me why

When x gets large, the ax2 term dominates. If a is positive, both arms end up high (∪); if negative, both arms end up low (∩).

A parabola is symmetric. Its two roots (when it has them) sit the same distance either side of the vertex, so the vertex x is their average: r1 + r22 = −b2a.

Why b2 − 4ac decides

It's the part under the square root in the quadratic formula, called the discriminant.

The 3 cases

All three use y = x2 − 2x + c. Only c changes, which slides the same curve up.

2 roots: x2 − 2x − 3 = 0

  • Discriminant (−2)2 − 4(1)(−3) = 16 → positive
  • Factor: multiply to −3, add to −2 → −3 and 1 → (x − 3)(x + 1)
  • Roots x = 3, x = −1
  • Vertex at y = −4, below the axis, arms go up → must cross twice.

1 root: x2 − 2x + 1 = 0

  • Discriminant 4 − 4 = 0
  • Perfect square → (x − 1)2
  • Root x = 1, a double root
  • Vertex sits on the axis; the curve touches and turns back.

0 roots: x2 − 2x + 2 = 0

  • Discriminant 4 − 8 = −4 → negative
  • No pair multiplies to 2 and adds to −2
  • Lowest point is y = 1, already above the axis.
  • Later in math: two complex roots, 1 ± i.

Shortcuts & special cases

  • Opposite signs shortcut: if a and c have opposite signs, there are always 2 roots.
  • Perfect-square test: if b2 − 4ac is a perfect square (0, 1, 4, 9, 16…), it factors with whole numbers. If not, go straight to the formula.
  • Downward parabolas (a < 0): the vertex is the highest point. Vertex above the axis → 2 roots, on → 1, below → 0. The discriminant rule is unchanged.
Show me why the opposite-signs shortcut works

If a and c have opposite signs, ac is negative, so −4ac is positive. b2 is never negative. Positive plus non-negative is positive, so the discriminant is positive → 2 roots.

Graph version: with a > 0 and c < 0, the curve opens up but passes through (0, c), which is below the axis. A ∪ that dips below the axis has to cross it twice.

Same signs tell you nothing by themselves: you have to compare b2 with 4ac.

Factoring

Remember this: only 3 things

  1. Why it works: if A · B = 0, then A = 0 or B = 0. Turn the equation into two brackets and solve each one.
  2. The one rule: find two numbers that multiply to a · c and add to b.
  3. Signs: c positive → both numbers take b's sign. c negative → opposite signs; the bigger one takes b's sign.

Everything else is this rule in disguise. When a = 1, a · c is just c. A perfect square is a pair that's the same number twice.

Steps

  1. Standard form: everything on one side, = 0.
  2. Clean up: if a is negative, factor out −1; if every term shares a factor (GCF), factor it out. These pulled-out numbers never give a root.
  3. Find the pair: multiply to a · c, add to b.
  4. Build the brackets: a = 1 → write (x + m)(x + n) directly. a > 1 → split the middle term with the pair, group into two halves, factor each, pull out the matching bracket.
  5. Solve: set each bracket to 0. With (x + m), the answer is x = −m: the sign flips.
  6. Check: plug each answer into the original; it should give 0.

a = 1: x2 − 3x − 10 = 0

  1. Multiply to −10, add to −3: try (1, −10) → −9 · (−1, 10) → 9 · (2, −5) → −3 ✓
  2. (x + 2)(x − 5) = 0
  3. x = −2 or x = 5
  4. Check: 25 − 15 − 10 = 0 ✓

a > 1: 2x2 + 7x + 3 = 0

  1. a · c = 6, add to 7 → 6 and 1
  2. Split: 2x2 + 6x + x + 3
  3. Group: 2x(x + 3) + 1(x + 3)
  4. (2x + 1)(x + 3) = 0 → x = −12 or −3

If the brackets after grouping don't match, re-check the pair and its signs. If the second half starts with a minus, factor out a negative so they line up.

Common factor: 2x2 + 4x − 6 = 0

  1. Take out 2 → 2(x2 + 2x − 3) = 0
  2. Multiply to −3, add to 2 → 3 and −1
  3. 2(x + 3)(x − 1) = 0 → x = −3 or 1. The 2 is never zero, so it's not a root.

Negative a: −x2 + x + 6 = 0

  1. Take out −1 → −(x2 − x − 6) = 0
  2. Multiply to −6, add to −1 → −3 and 2
  3. −(x − 3)(x + 2) = 0 → x = 3 or −2

Perfect square trinomial (1 repeated root)

The pair is the same number twice. x2 + 2x + 1: multiply to 1, add to 2 → 1 and 1 → (x + 1)2.

How to spot one

  • First and last terms are perfect squares, and the middle term is 2 × their square roots.
  • x2 − 6x + 9: 2 · x · 3 = 6x ✓ → (x − 3)2, double root x = 3.
  • The last term must be positive. x2 + 6x − 9 is not a perfect square.
Show me why a double root only touches the axis

(x + 1)2 is a square, so it's never negative. It equals 0 only at x = −1. Everywhere else the curve is above the axis, so at that one point it touches (is tangent) instead of crossing. That point is the vertex.

The formula

x = −b ± √b2 − 4ac2a

  • The −b means “flip the sign of b”. If b = −6, then −b = 6.
  • Square negatives with brackets: (−6)2 = +36.
  • Divide the whole top by 2a, not just the square root.
  • Simplify the root: √48 = √16 · 3 = 4√3, then cancel any common factor.

Other heights

To find where the curve crosses y = k, solve ax2 + bx + c = k. Move k to the left first so it's = 0, then solve as usual.

Example: where does y = x2 − 2x − 3 meet y = 5?

  1. x2 − 2x − 3 = 5 → x2 − 2x − 8 = 0
  2. (x − 4)(x + 2) = 0 → x = 4 or −2

SAT extras Beyond your notes

These show up often on the SAT and in Algebra 2. They're not in your vault notes yet.

Difference of squares L1

A2 − B2 = (A − B)(A + B). No middle term.

4x2 − 9 = (2x − 3)(2x + 3) → x = ±32.

A sum of squares, x2 + 9, doesn't factor and has no real roots.

Sum & product of roots L2

Sum = −ba, product = ca. No need to solve.

For 2x2 − 6x + 1 = 0: sum = 3, product = 12.

Vertex form / completing the square L2

y = a(x − h)2 + k has vertex (h, k). Watch the sign: (x + 3)2 means h = −3.

To convert x2 + bx + c: halve b, square it, add and subtract it. x2 − 6x + 11 = (x − 3)2 − 9 + 11 = (x − 3)2 + 2.

Unknown coefficient k L3

“Exactly one solution” → set b2 − 4ac = 0. “No real solutions” → < 0. “Two solutions” → > 0. Then solve for k.

x2 + 8x + k = 0 has one solution → 64 − 4k = 0 → k = 16.

Parabola meets a line L3

Set the two equal, move everything to one side, then use the discriminant to count intersection points.

x2 + 1 = 2x → x2 − 2x + 1 = 0, discriminant 0 → the line is tangent: 1 point.

Everything to memorize on one page. Read it, cover it, say it back.

Shape

  • ax2 + bx + c, a ≠ 0
  • a > 0 → ∪ (min), a < 0 → ∩ (max)
  • Vertex x = −b / 2a; plug in for y
  • y-intercept is (0, c)
  • Roots = x-intercepts = where y = 0

Count the roots

  • D = b2 − 4ac
  • D > 0 → 2 · D = 0 → 1 (double) · D < 0 → 0 real
  • a, c opposite signs → always 2
  • D a perfect square → factors with whole numbers
  • Vertex below/on/above axis (∪) → 2 / 1 / 0. Flip for ∩.

Factoring rule

  • Two numbers: × to a·c, + to b
  • c + → both take b's sign
  • c − → opposite signs; bigger takes b's sign
  • a > 1: split middle, group, pull out the common bracket
  • Pull out −1 and GCF first. They are never roots.

Solving

  • A·B = 0 ⇒ A = 0 or B = 0 (only works with 0!)
  • (x + 3) = 0 → x = −3: the sign flips
  • (2x − 5) = 0 → x = 5/2: divide by the x number
  • Other heights: … = k → move k over first
  • Check by plugging back in

Quadratic formula

x = −b ± √b2 − 4ac2a

  • −b: flip b's sign
  • (−b)2 is positive
  • Divide the whole top by 2a
  • Simplify √, cancel common factors

Perfect squares

  • (x + p)2 = x2 + 2px + p2
  • Ends are squares, middle is 2 × roots, last term positive
  • One double root; graph touches at the vertex

SAT extras Beyond notes

  • A2 − B2 = (A − B)(A + B); x2 + B2 doesn't factor
  • Sum of roots −b/a, product c/a
  • Vertex form a(x − h)2 + k → vertex (h, k)
  • Complete the square: add & subtract (b/2)2
  • “One solution” ⇔ D = 0; “none” ⇔ D < 0
  • Parabola ∩ line: set equal, move to one side, use D

Common traps

  • Reading a from the first term when x2 isn't first
  • Forgetting the minus in −b/2a
  • Writing −32 = −9 inside b2
  • Keeping the bracket's sign for the root
  • Counting a pulled-out GCF as a root
  • Setting brackets equal to a non-zero number
